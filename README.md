# 🏏 ODI World Cup 2023 – Power BI Dashboard

### Cricket Performance & Statistical Analysis

An interactive Power BI dashboard built to analyze the ICC Men's Cricket World Cup 2023. This project provides insights into team performance, player statistics, match results and tournament records through interactive visualizations.

---

## 📊 Dashboard Preview

Explore the tournament through four interactive dashboard pages:

### 🏠 1. Home Page
- Overall tournament statistics.
- Total Matches, Runs, Fours, Sixes and Wickets.
- Top Run Scorer.
- Top Wicket Taker.
- Most Sixes.
- Interactive page navigation.

### 🏆 2. Team Performance
- Team-wise Total Runs.
- Team-wise Total Wickets.
- Average Runs per Match.
- Total Fours and Sixes.
- Team Performance Comparison.
- Interactive Team Slicer.

### 🏏 3. Player Performance
- Top Run Scorers.
- Top Wicket Takers.
- Player-wise Total Runs.
- Player-wise Fours and Sixes.
- Total Runs and Boundary Analysis.
- Interactive Player and Team Slicers.

### 📈 4. Match Analysis
- Total Matches and Runs.
- Average Runs per Match.
- Match-wise Performance.
- Venue Analysis.
- City-wise Total Runs.
- Date-based Analysis.
